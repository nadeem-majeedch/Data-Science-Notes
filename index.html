Data Science Notes

Free, complete Introduction to Data Science course notes for beginners. Simple explanations, beginner examples, and expert-level production examples for every topic.

View on GitHub

What You Will Learn

  • Data science fundamentals — types of data, measurement scales, collection methods, data science lifecycle (CRISP-DM, OSEMN)
  • Data processing & wrangling — cleaning, missing values, outliers, transformation, integration, dimensionality reduction (PCA)
  • EDA & visualization — descriptive statistics, Matplotlib & Seaborn, hypothesis testing, time-series forecasting
  • Programming & tools — Python (NumPy, Pandas, Scikit-learn), R, SQL, Git, command line
  • Machine learning — regression, classification, ensembles (Random Forest, XGBoost), clustering, model evaluation
  • Big data & databases — SQL vs NoSQL, Hadoop, Spark, Hive, data warehouses & lakes
  • Data ethics, governance & communication — fairness, privacy, storytelling, reproducibility
  • Emerging topics — deep learning, NLP, cloud computing, MLOps
